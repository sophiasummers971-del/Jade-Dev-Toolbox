# Agent Instructions

This repository is a public, sanitized technical toolbox.

## Operating rule
Before solving a development problem:
1. Read `INDEX.md`.
2. Use the relevant guide/checklist/skill.
3. Inspect the actual target repository or service before acting.
4. Treat live repository/configuration state as authoritative over this toolbox.
5. Update this toolbox only with reusable, non-sensitive knowledge.

## Never add
Secrets, credentials, tokens, private keys, personal memory, legal/medical records, private account data, private correspondence, or transient chat history.

## Verification language
Use only:
- **VERIFIED**: directly checked.
- **REFERENCE**: reusable guidance not verified for the current target.
- **STALE**: known to require re-verification.

Never convert a remembered claim into VERIFIED status.

## Change safety
Read-only inspection comes first. Implementation, push, merge and deployment are separate permissions/actions. Do not infer permission for a later action from permission for an earlier one.
