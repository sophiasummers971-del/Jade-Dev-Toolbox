# Toolbox Security Rules

Never store passwords, API/access/refresh tokens, private keys, seed phrases, recovery codes, session cookies, government/account identifiers, personal legal/medical records, or unredacted environment files.

Use placeholders for secrets.

Treat commands copied from public Gists, forums and AI output as untrusted until inspected.

If a secret is accidentally committed, deleting the visible line is not sufficient. Rotate/revoke it and clean history where appropriate.
