# Skills Catalogue

These are small reusable procedures. They are intentionally platform-neutral where possible.

| Skill | Purpose | Default mode |
|---|---|---|
| `project-baseline.md` | Establish current project truth before work | Read-only |
| `dependency-repair.md` | Repair dependency/security alerts conservatively | Change-capable |
| `release-verification.md` | Verify a release without assuming deployment success | Read-only |
| `incident-triage.md` | Investigate a broken build/deploy/runtime path | Read-only first |
| `knowledge-harvest.md` | Turn a solved problem into safe reusable knowledge | Documentation |

A skill is a procedure, not proof. Current state must still be inspected.
