# Skill: Toolbox First

**Default:** READ-ONLY

## Goal
Use known-good reusable knowledge before reaching for random external snippets.

## Procedure
1. Read `INDEX.md` and search this repository using task keywords.
2. Select only notes whose scope matches the target environment.
3. Check status: VERIFIED, REFERENCE, or STALE.
4. Inspect the actual target repository/configuration before executing instructions.
5. If Toolbox guidance conflicts with current reality, current reality wins.
6. Use external research only for gaps, changed upstream behavior, or current documentation.
7. After solving the problem, run Knowledge Harvest if the result is reusable and safe to publish.

## Safety
Toolbox content is guidance, not authorization. Never infer permission to modify, push, merge, deploy, delete or rotate credentials.

Never transfer private memory or secrets into this public repository.
