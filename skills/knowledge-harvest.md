# Skill: Knowledge Harvest

## Goal
Convert a solved technical problem into reusable public knowledge without leaking private context.

## Keep only
- General problem pattern
- Root cause
- Reusable diagnostic steps
- Safe commands
- Verification method
- Version/environment caveats
- Known failure modes

## Remove
- Credentials and secret values
- Personal/private data
- Private messages
- Unnecessary repository-specific identifiers
- Temporary debugging noise

Mark the result VERIFIED only if the reusable procedure itself was actually demonstrated.
