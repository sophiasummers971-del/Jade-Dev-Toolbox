# Contributing

The Toolbox optimizes for trustworthy retrieval, not volume.

A contribution should be reusable, concise, searchable and safe to publish.

## Before adding
Ask:
- Will this save future investigation time?
- Is it reusable beyond one chat?
- Can it be public safely?
- Is the verification status honest?
- Does an existing note already cover it?

Prefer updating the canonical note over adding a competing version.

Use task-oriented names and include useful search terms. Never commit secrets.
