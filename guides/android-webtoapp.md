# Android / WebView / WebToApp

**Status:** REFERENCE

For web-first Android packaging, preserve browser/WebView-compatible APIs and avoid making desktop-native filesystem APIs mandatory.

Check touch targets, phone-sized layouts, alternatives to drag-and-drop, browser-compatible file selection, promised offline behavior, persistence across restart, and production `dist/` behavior.

A feature working on localhost is evidence, not proof that the packaged Android app works.
