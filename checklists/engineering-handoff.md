# Engineering Handoff / Start Checklist

**Status:** REFERENCE

Capture: repository, canonical branch, verified baseline SHA, working branch, goal, non-goals, constraints, required checks, merge permission, deployment permission.

Completion report: final branch/SHA, areas changed, behavior implemented, verification PASS/FAIL/NOT RUN, limitations, and whether anything was pushed/merged/deployed.

This prevents an old chat claim from becoming repository truth.
