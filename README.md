# Jade Dev Toolbox 🧰

A searchable, reusable technical knowledge base for Jade's development work.

## Start here
Use **INDEX.md** before searching the wider web or copying random snippets.

## Core rules
1. Search this toolbox first.
2. Prefer verified project patterns over random internet snippets.
3. Never store passwords, API keys, access tokens, private keys, recovery codes, personal/legal records, or other secrets.
4. Mark risky commands clearly.
5. Record what was actually verified. Never turn an assumption into a fact.
6. Project-specific facts belong in `projects/`; reusable lessons belong in `guides/`.
7. Replace stale instructions rather than accumulating contradictory versions.

## Knowledge status
- **VERIFIED**: actually tested or confirmed.
- **REFERENCE**: useful guidance, but environment/version may differ.
- **STALE**: historical only; re-verify before use.

This repository is documentation, not a secrets vault.
